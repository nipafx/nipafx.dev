From pattern matching to virtual threads and startup time improvements, Java has made big strides in recent years.
And it's not done yet!
With value types entering the language and structured concurrency finalizing, it currently takes another two big steps into the future.
And what's waiting there?
More startup and warmup time improvements, a more powerful type system and runtime, deeper progress into data-centric programming, and native AI capabilities.
Let's have a look!
