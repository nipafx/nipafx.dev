Java 25 is the latest release with wide-ranging long-term support.
It's a doozy but new releases followed hot on its heels and delivered a lot, particularly Java 28:

* from module imports to improved pattern matching
* from structured concurrency to PEM and HTTP/3
* from incubating lazy constants and a JSON API to previewing primitive patterns and value classes (!)
* from faster launches and better performance to quantum-resistant encryption

There are plenty of features in the language, API, and runtime to discuss - whether new, improved, or finalized.
So let's go over them!
